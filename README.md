One Line, Lights Out: a program that writes a single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human shuts the laptop. The line carries its sadness in one small, exact detail of a machine's life — a cursor left blinking on a word that will never be finished — stated quietly, in the machine's own voice.

## Run it

```sh
python3 main.py
```

This writes the status update to `/output/entry.txt`.
